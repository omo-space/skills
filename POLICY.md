# Omo Open-Source Policy (canonical)

- ALL Omo teacher tools and `SKILL.md` files are open-sourced here on GitHub
  under the **omo-space** organization — free to download and reuse (MIT).
  The paid product is the **hosted run** on [omo.space](https://omo.space):
  pay per run, no subscription.
- **EXCEPTION — NEVER open-source: the Phonics Book Maker**
  (`illustrated-decodable-story-maker`, the flagship book-builder). It is
  **PRIVATE** and its SKILL.md is sold for **$400** on the marketplace.
  Never create a public repo, or push any file, for the book maker. Keep it
  private, chargeable, and exclusive.
- Every skill folder carries the SKILL.md with this policy header, an MIT
  LICENSE, and a manifest.json (slug, version, hosted run price,
  inputs/outputs, source SHA-256).
- Repos get SEO-friendly names + topics (skill-md, ai-skill, phonics,
  education, agents) and link back to omo.space.

Questions or a skill you want added? Open an issue — this is a community repo.
